## Run locally

1. Create and activate a Python virtual environment.
2. Install dependencies with `pip install -r requirements.txt`.
3. Run migrations with `python manage.py migrate`.
4. Start the development server with `python manage.py runserver`.

The project settings and template configuration are included in
`atlascloud-project.json`. This starter is not deployed by AtlasCloud.

The included settings are for local development only. Set `DJANGO_SECRET_KEY`
to a private value and review `DEBUG` and `ALLOWED_HOSTS` before any
production use.
